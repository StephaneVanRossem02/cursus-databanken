# MySQL Workbench

Download: <https://dev.mysql.com/downloads/workbench/>

[https://youtu.be/YTO44aLbGMk](https://youtu.be/YTO44aLbGMk)
installatie MySQL Workbench

## Login

Basisscherm MySQL Workbench:

![](/img/databanken/image_4_.png)

**Stap 1:** Klik op het plusje.

![](/img/databanken/image_5_.png)

**Stap 2:** Vul de juiste gegevens in:

- **Hostname:** localhost
- **Username:** root

Default schema laat je leeg.

Je klikt na het invullen van de juiste gegevens op de knop "**Store in Vault**" en vult het paswoord van je root-gebruiker in.

![](/img/databanken/image_3_.png)

**Stap 3:** Connectie testen.

Je moet volgende boodschap krijgen.

![](/img/databanken/image-5.png)
