# MySQL Server

## Inleiding

Tijdens de labo’s over SQL werken we met MySQL. We zullen je nu door de installatie van deze software te leiden. We zullen eerst de server kant van de software installeren. Daarna zullen we een client (MySQL Workbench) installeren waarmee we naar deze server kunnen connecteren.<br>

## Benodigde software

**Stap 1:** Download eerst het installatiebestand vanop de URL [https://dev.mysql.com/downloads/installer/](https://dev.mysql.com/downloads/installer)

**Stap 2:** Download het installatiebestand dat alle componenten bevat (grootste filesize)

![](/img/databanken/Screenshot_2024-02-03_155152.png)

## Installatie

**Stap 3:** Voer het gedownloade msi bestand uit.

**Stap 4:** Bij de keuze voor Setup Type kies je de optie Full.

![](/img/databanken/Screenshot_2024-02-03_155418.png)

**Stap 5**: Klik op de knop Next.

**Stap 6:** In geval je een foutmelding krijgt omtrent een component van Python mag je deze negeren. Dit is een component die we niet zullen gebruiken. Klik hier dus op Next en vervolgens op Yes in het dialoogvenster.

**Stap 7**: Klik op de knop Execute om de installatie te starten.

**Stap 8:** De installatiewizard toont de voortgang per component.

![](/img/databanken/Screenshot_2024-02-03_165109.png)

**Stap 9:** Wanneer alle componenten geïnstalleerd zijn klik je op de knop Next om naar volgende stap te gaan.

![](/img/databanken/image.png)

**Stap 10:** Klik in de stap Product Configuration op de knop Next.

![](/img/databanken/Screenshot_2024-02-03_165727.png)

**Stap 11:** Bij Type and Networking laat je het Config Type staan op Development Computer.

![](/img/databanken/image-2.png)

**Stap 12:** Bij de Authentication Method kies je de optie “Use Strong Password …”

**Stap 13:** Klik vervolgens op de knop Next.

**Stap 14:** Geef het wachtwoord op. Om ervoor te zorgen dat je dit niet vergeet gebruik je als wachtwoord best het woord ‘root’.

![](/img/databanken/Screenshot_2024-02-03_170214.png)

**Stap 15:** Klik 2 maal op de knop Next.

**Stap 16:** Klik op execute.

![](/img/databanken/image-3.png)

**Stap 17:** Klik in het volgende scherm op de knop Finish om het configuratieproces af te ronden.&#x20;

![](/img/databanken/Screenshot_2024-02-03_171601.png)

**Stap 18:** Klik in het volgende scherm op de knop Next om de configuratie van de Router component te starten.

![](/img/databanken/Screenshot_2024-02-03_171801.png)

**Stap 19:** Laat in het volgende scherm alles staan zoals het is en klik op de knop Finish.

![](/img/databanken/Screenshot_2024-02-03_172150.png)

**Stap 20:** Klik 2 maal op de knop next

**Stap 21:** Klik vervolgens op de knop Execute om de configuratie uit te voeren.

![](/img/databanken/image-4.png)

**Stap 22:** Klik daarna op de knop Finish om de configuratie af te ronden.

![](/img/databanken/Screenshot_2024-02-03_172606.png)
