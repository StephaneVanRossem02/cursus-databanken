# DML

De belangrijkste commando's van de DML zijn:

* `INSERT`: Hiermee voeg je data in
* `SELECT`: Hiermee vraag je data op
* `UPDATE`: Hiermee pas je data aan
* `DELETE`: Hiermee verwijder je data
