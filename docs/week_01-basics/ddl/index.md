# DDL

De belangrijkste commando's van de DDL zijn:

* `CREATE`: Hiermee maak je nieuwe structuren aan.
* `ALTER`: Hiermee verander je bestaande structuren.
* `DROP`: Hiermee wis je bestaande structuren.
